# sf-spec: устройство

Как выполнены [требования этапа](requirements.md). Зависит от [общего устройства](../core/design.md).

Документы, которые скилл читает после `status`: `brainstorming.md`, `questions.md`, `spec.md`, если он есть.

## Подготовка требований

- У каждого FR есть хотя бы один пример. `check` проверяет только наличие примера, смысл оценивает агент.
- Основание FR — только решение `D-…`. Когда пользователь отвечает на вопрос `Q-…`, агент записывает решение `D-…` со ссылкой на этот вопрос.
- Остаётся модели: формулировка FR и примеров по принятым решениям, без несогласованного (FR-14). Пробел, найденный при подготовке, записывается в `questions.md`, а блокирующий обсуждается сразу (FR-15).
