# План реализации Spec Forge

Временный документ: порядок реализации, отложенные решения и подсказки к блокам. Устройство системы описано в [design.md](design.md) и `design.md` этапов как готовое. После блока 7 этот файл удаляется.

Каждый блок делается двумя PR — критерии и реализация; порядок — в [AGENTS.md](../../AGENTS.md).

## Блоки

1. Манифест, MCP-сервер с пустыми `status`, `check` и `link`, правила без образцов записей, тесты обмена с MCP-сервером.
2. `status`: выбор задачи, проверка имени папки, этап и следующий шаг, проверка источников, задание на изучение. `check` для `_work/context.md`.
   - Для подсказок перехода можно адаптировать приёмы сопровождения переходов из sdd-planner.
3. `check` для `brainstorming.md` и `questions.md`: формат, номера, блокирующие вопросы, следующие свободные номера. Образцы `D-…` и `Q-…` в правилах. Скилл `sf-grill` с `grilling`.
   - До критериев решить: `SKILL.md` пишет агент реализации или он входит в PR критериев.
   - Для образца `brainstorming.md` можно адаптировать шаблон `skills/sdd-grill/assets/brainstorming.md` из sdd-planner.
4. `check` для `spec.md`: пример и основание FR, заменённые основания, ссылки, размер, строка статуса и приведение текста перед подсчётом суммы, условия одобрения. `link`. Скилл `sf-spec`.
   - Для образца FR можно адаптировать шаблон `skills/sdd-spec/assets/spec.md` из sdd-planner.
5. `check` для `review.md`. Скилл `sf-review`.
6. Изменение после одобрения через git, список зависящих FR. Скилл `sf-note`.
   - До критериев решить: как действовать, если одобренной версии `spec.md` в истории git нет ([sf-note/design.md](../sf-note/design.md)).
7. Ручной прогон проверочных ситуаций в GigaCode CLI на трёх моделях. По его итогам — решение о пишущих действиях.
   - Риски `sf-grill`: английский текст `grilling` при русском общении может увести ответы модели на английский; правило «каждый поиск фактов — отдельным агентом» может оказаться тяжёлым для простой задачи.

## Отложено

- Пишущие действия сверх `link` — до ручного прогона (блок 7).
- Передача правила именования папок через контекст пользователя.
- Напоминание о коммите после одобрения.
