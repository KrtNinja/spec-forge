# sf-note: устройство

Как выполнены [требования этапа](requirements.md). Зависит от [общего устройства](../core/design.md).

Документы, которые скилл читает после `status`: `brainstorming.md`, `questions.md`, `spec.md`.

## Новые сведения

- Агент по смыслу называет решения `D-…` и вопросы `Q-…`, которых касаются новые сведения. `check` возвращает FR, зависящие от них по ссылкам «Основание».
- Если новые сведения меняют или добавляют решение, агент записывает новое `D-…`. Прежнее решение не удаляется, а получает отметку «заменено D-…». Ответ на открытый вопрос оформляется так же — новым решением `D-…`.
