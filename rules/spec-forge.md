# Spec Forge

- В вопросах, рекомендациях, объяснениях и документах используй понятный русский язык. Избегай англицизмов, кальки и технического жаргона, если есть понятный русский вариант. Необходимые термины кратко объясняй при первом использовании. Точные имена команд, файлов, технологий и идентификаторы сохраняй.
- Решения о поведении и границах задачи принимает пользователь. Отделяй свои рекомендации от его решений; требования отмечай одобренными только по его явному решению.
- После правки документов задачи Spec Forge вызови `spec_forge` с действием `check` и исправь ошибки. Номера новых записей бери из его строки «Следующие номера».
- Не пересказывай ответ инструмента: пользователь уже видит его целиком.
- Вызов `spec_forge` не удался — предупреди пользователя и не сообщай о действии как о выполненном.

## Записи

Решение — в разделе «Решения» `brainstorming.md`:

```markdown
### D-04

- Вопрос: что видит покупатель, если заказ не найден?
- Рекомендация: сообщение «Заказ не найден»
- Решение: как рекомендовано, и ссылка на историю заказов
```

Вопрос — в `questions.md`:

```markdown
### Q-02

Сколько хранить историю поиска?

- Этап: sf-grill
- Блокирует: нет
- Помощь: бизнес — срок хранения задаёт юрист
- Статус: открыт
- Ответ:
```

- «Рекомендация» — только если ты её давал. Записи не удаляй: пользователь изменил решение — новая запись, а в прежней `- Заменено: D-09`.
- Пользователь не может ответить — запиши вопрос, ответ не выдумывай. «Этап» — команда, на которой вопрос возник.
- «Блокирует: да» — без ответа не определить основное поведение или ответ может существенно изменить требования. Объясни пользователю, что мешает; независимые темы обсуждай дальше.
- «Статус»: `открыт`, `решён` или `не входит`. Отложенный вопрос остаётся открытым; `не входит` — только по явному решению пользователя, с «Ответом» и номером вопроса в «Не входит в задачу».
- Пришёл ответ — выясни вопросы, которые он породил, обнови решения, а если есть требования — и их. Затем запиши решение с номером вопроса (`- Вопрос: Q-02`), а в вопросе — «Ответ» и `решён`.
