# Поиск заказа по номеру

## Запрос

Покупатель ищет свой заказ по номеру. Начало — [D-01](#d-01) и вопрос [Q-01](questions.md#q-01).

## Источники

- `docs/D-01-protocol.md` — протокол

## Решения

### D-01

- Вопрос: [Q-01](questions.md#q-01)
- Решение: искать по полному номеру.

### D-02

- Вопрос: что видит покупатель, если заказ не найден?
- Решение: сообщение «Заказ не найден», как в [D-01](#d-01) для найденного.
- Заменено: [D-03](#d-03)

### D-03

- Решение: сообщение и ссылка на историю заказов; требование — [FR-02](spec.md#fr-02).

## Не входит в задачу

- Поиск по телефону — [`Q-02`](questions.md#q-02)
