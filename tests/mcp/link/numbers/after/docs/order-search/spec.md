# Поиск заказа по номеру

Статус: черновик

## Цель

Покупатель находит заказ по номеру из письма ([D-01](brainstorming.md#d-01)).

## Требования

### FR-01

Покупатель вводит полный номер и видит свой заказ.

- Пример: Анна вводит 10234 — видит заказ 10234
- Основание: [D-01](brainstorming.md#d-01)

### FR-02

Не найденный заказ — сообщение и ссылка на историю заказов, в отличие от [FR-01](#fr-01).

- Пример: Анна вводит 99999 — видит «Заказ не найден» и ссылку на историю
- Основание: [D-03](brainstorming.md#d-03)

Так записывается основание:

```markdown
- Основание: D-01
```
