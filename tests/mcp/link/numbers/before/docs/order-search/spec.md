# Поиск заказа по номеру

Статус: черновик

## Цель

Покупатель находит заказ по номеру из письма (D-01).

## Требования

#### `FR-01` Поиск по полному номеру

Покупатель вводит полный номер и видит свой заказ.

> Пример: Анна вводит 10234 — видит заказ 10234

<sub><sup>Основание: D-01</sup></sub>

#### `FR-02` Заказ не найден

Не найденный заказ — сообщение и ссылка на историю заказов, в отличие от FR-01.

> Пример: Анна вводит 99999 — видит «Заказ не найден» и ссылку на историю

<sub><sup>Основание: D-03</sup></sub>

Так записывается основание:

```markdown
<sub><sup>Основание: D-01</sup></sub>
```

- Поиск по телефону: Q-02
