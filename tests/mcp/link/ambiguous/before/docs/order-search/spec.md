# Поиск заказа

Статус: черновик

## Цель

Покупатель находит заказ по номеру.

## Требования

#### `FR-01` Поиск по полному номеру

Покупатель вводит номер и видит свой заказ.

> Пример: Анна вводит 10234 — видит заказ 10234

<sub><sup>Основание: D-01, [D-01](questions.md#d-01), D-02</sup></sub>

## Не входит в задачу

- Поиск по части номера — D-01
