# Поиск заказа по номеру

Статус: черновик

## Цель

Покупатель находит свой заказ по номеру.

## Требования

### FR-01

Покупатель вводит полный номер и видит свой заказ.

- Пример: Анна вводит 10234 — видит заказ 10234
- Основание: D-01

### FR-03

Неполный номер — сообщение «Введите номер полностью».

- Пример: Анна вводит 102 — «Введите номер полностью»; вводит 10234 — видит заказ
- Основание: [D-03](brainstorming.md#d-03)
