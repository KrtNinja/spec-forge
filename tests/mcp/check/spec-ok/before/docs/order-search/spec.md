# Поиск заказа по номеру

Статус: черновик

## Цель

Покупатель находит свой заказ по номеру из письма, не листая историю заказов. Как устроен раздел — [цель](#цель).

## Требования

### FR-01

Покупатель вводит полный номер заказа в личном кабинете и видит карточку своего заказа.

- Пример: Анна вводит 10234 — открывается её заказ 10234 «Доставлен»
- Основание: [D-01](brainstorming.md#d-01)

### FR-02

Не найденный заказ — сообщение «Заказ не найден» и ссылка на историю заказов, как в FR-01 для найденного.

- Пример: Анна вводит 99999 — видит «Заказ не найден» и ссылку на историю
- Основание: [`D-03`](brainstorming.md#d-03), D-01

Так записывается требование:

```markdown
Статус: одобрено 2026-11-06 · a1b2c3

### FR-09

- Основание: D-09
```
