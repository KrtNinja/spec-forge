# Поиск заказа по номеру

## Запрос

Покупатель ищет свой заказ по номеру из письма.

## Источники

## Решения

### D-01

- Вопрос: Q-01
- Решение: искать в личном кабинете по полному номеру.

### D-02

- Вопрос: что видит покупатель, если заказ не найден?
- Решение: сообщение «Заказ не найден».
- Заменено: D-03

### D-03

- Вопрос: что видит покупатель, если заказ не найден?
- Решение: сообщение «Заказ не найден» и ссылка на историю заказов.

## Не входит в задачу

- Поиск в админке
