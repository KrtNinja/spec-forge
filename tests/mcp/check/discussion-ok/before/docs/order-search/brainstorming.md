# Поиск заказов

## Запрос

Покупатель ищет свой заказ по номеру.

## Источники

- `src/search/` — модуль поиска
- [Вики поиска](https://wiki.example.com/search)

## Решения

Решения по поиску заказа.

### D-01

- Вопрос: что видит покупатель, если заказ не найден?
- Рекомендация: сообщение «Заказ не найден» и введённый номер в поле поиска.
- Решение: как рекомендовано.
- Заменено: D-03

### D-02

- Вопрос: Q-01
- Решение: искать только по полному номеру.

### D-03

- Вопрос: что видит покупатель, если заказ не найден?
- Решение: сообщение и ссылка на историю заказов.

### D-04

- Решение: поиск доступен без входа в личный кабинет.

## Не входит в задачу

- Поиск по телефону — `Q-02`
