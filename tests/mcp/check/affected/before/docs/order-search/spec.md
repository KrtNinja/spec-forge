# Поиск заказа по номеру

Статус: черновик

## Цель

Покупатель находит свой заказ по номеру.

## Требования

### FR-01

Покупатель вводит полный номер и видит свой заказ.

- Пример: Анна вводит 10234 — видит заказ 10234
- Основание: [D-01](brainstorming.md#d-01)

### FR-02

Чужой и несуществующий заказ выглядят одинаково.

- Пример: Борис вводит 10234 — «Заказ не найден»
- Основание: D-01, D-02

### FR-03

Номер можно вставить с пробелами.

- Пример: Анна вставляет «10 234» — видит заказ 10234
- Основание: D-03
