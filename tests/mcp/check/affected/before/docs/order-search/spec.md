# Поиск заказа по номеру

Статус: черновик

## Цель

Покупатель находит свой заказ по номеру.

## Требования

#### `FR-01` Поиск по полному номеру

Покупатель вводит полный номер и видит свой заказ.

<sub><sup>Основание: [D-01](brainstorming.md#d-01)</sup></sub>

#### `FR-02` Чужой и несуществующий заказ

Чужой и несуществующий заказ выглядят одинаково.

> Пример: Борис вводит 10234 — «Заказ не найден»

<sub><sup>Основание: D-01, D-02</sup></sub>

#### `FR-03` Пробелы в номере

Номер можно вставить с пробелами; дальше поиск тот же, что по D-01.

> Пример: Анна вставляет «10 234» — видит заказ 10234

<sub><sup>Основание: D-03</sup></sub>
