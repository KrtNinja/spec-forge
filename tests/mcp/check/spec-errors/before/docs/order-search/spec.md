# Поиск заказа по номеру

Статус: одобрено 06.11.2026 · a1b2c3

## Требования

Требования к поиску. Подробнее — FR-08.

### FR-01

Покупатель вводит полный номер заказа и видит свой заказ.

- Основание: D-01

### FR-1

Номер ищется без учёта пробелов.

### Поиск по части номера

Не ищется.

### FR-01

Чужой заказ не показывается.

- Пример: Борис вводит 10234 — «Заказ не найден»
- Пример: Анна вводит 10234 — видит свой заказ
- Основание: D-01

### FR-03

Не найденный заказ — сообщение «Заказ не найден».

- Пример: Анна вводит 99999 — «Заказ не найден»

### FR-04

История поиска не хранится.

- Пример: Анна обновляет страницу — поле поиска пустое
- Основание: решение о хранении, Q-01

### FR-05

Не найденный заказ — сообщение и ссылка на историю.

- Пример: Анна вводит 99999 — сообщение и ссылка на историю
- Основание: D-02, D-09

### FR-06

Ссылки в требовании.

- Пример: [протокол](protocol.md), [решение](brainstorming.md#d-07), [схему](brainstorming.md#D-01), ![D-01](схема.png)
- Основание: [D-01](questions.md#d-01)

### FR-07

Поиск доступен и без входа.

- Пример: гость вводит номер — видит форму входа
- Основание: D-03
