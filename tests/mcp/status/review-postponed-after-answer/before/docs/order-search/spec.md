# Поиск заказа по номеру

Статус: черновик

## Цель

Покупатель находит свой заказ по номеру.

## Требования

### FR-01

Покупатель вводит полный номер и видит свой заказ. История поиска не сохраняется.

- Пример: Анна вводит 10234 — видит заказ 10234; после завершения поиска его история не сохраняется
- Основание: D-01, D-02
