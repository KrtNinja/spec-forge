# Spec Forge

Расширение для GigaCode CLI: скиллы, правила и проверки, которые помогают пройти путь от идеи в одну фразу до одобренных требований по подходу Spec-Driven Development — разработки на основе требований.

Результат — документы, по которым разработчик или агент может писать код, не угадывая, как должна вести себя система. Написание кода по подготовленным единицам работы — отдельная задача, которая не входит в Spec Forge.

Главные приоритеты — удобство пользователя и бережное отношение к контексту модели. Рутину и проверки берут на себя детерминированные инструменты, чтобы модель могла сосредоточиться на содержании и смысле требований.
